# Reconocimiento facial básico con Haar Cascades

## Instalación
```bash
source venv/bin/activate
pip install -r requirements.txt
```

## Descargar imagen de prueba
```bash
python3 src/download_test_image.py
```

## Ejecutar detección facial
```bash
python3 src/face_detection.py
```

Los resultados se guardan en `output/`.
